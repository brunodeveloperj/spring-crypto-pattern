# spring-crypto-pattern

A reusable Spring Boot library providing standardized encryption and decryption mechanisms for secure communication between frontend and backend applications.

## Features

- Encryption
- Decryption
- AES support
- RSA support
- Key management
- Secure payload handling
- Hybrid encryption support

---

## Supported Strategies

- AES
- RSA
- AES + RSA Hybrid

---

## Architecture

Frontend
↓
Public Key Encryption
↓
Backend
↓
Private Key Decryption
